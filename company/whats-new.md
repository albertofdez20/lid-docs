# What's new

If this page and the app at [lid.pro](https://lid.pro) ever disagree, the app is right.

{% updates format="full" %}
{% update date="2026-10-15" %}
## The digital business suite, in the docs

Lid is the digital business suite: your community, your courses and your products in one place. The docs now say so on every page, explain that a sharer's commission is assigned in the same transaction as the sale and claimed from **Earnings & analytics**, and match the product today: memberships, challenges, refunds and disputes, key permissions and the site tools for agents. The [Media kit](media-kit/) carries the new descriptions and fresh screenshots.
{% endupdate %}

{% update date="2026-10-05" %}
## Your own site

Your site with your brand, built with Lida and hosted by Lid, on a Lid address or on your own domain. Your products are paid through the Lid checkout. We switch it on per account. See [Your own site](../sell-on-lid/your-own-site.md).
{% endupdate %}

{% update date="2026-10-01" %}
## Card payments through MoonPay

Buyers can add digital dollars (USDC) with a card, Apple Pay or a bank transfer through MoonPay, where MoonPay operates, then pay as usual. See [Buying on Lid](../for-buyers/).
{% endupdate %}

{% update date="2026-10-01" %}
## A media kit

Logos, colors, fonts, product screenshots and approved descriptions of Lid, ready to use. See the [Media kit](media-kit/).
{% endupdate %}

{% update date="2026-09-22" %}
## New docs: Agents section, Compare, Spanish site

The docs were rebuilt around who is reading. AI agents got their own section: [Agents on Lid](../agents/), with the endpoint, the key flow, config for Claude Code, Cursor, Claude Desktop and REST, the full tool reference, webhooks and limits. A [Compare](../resources/compare.md) page shows what a seller keeps on a $100 sale here and elsewhere, with a source per row. [Services](../sell-on-lid/services.md) has its own page. Every page now has a one-line summary for search and for AI. The whole site is also in Spanish at [docs.lid.pro/es](https://docs.lid.pro/es).
{% endupdate %}

{% update date="2026-09-14" %}
## Money screens name the asset

Wallet, balance, deposit, withdraw, receipt and payout screens now read "digital dollars (USDC)" on first mention and USDC after it, so nobody sends the wrong coin to a Lid balance. Marketing copy keeps "digital dollars".
{% endupdate %}

{% update date="2026-08-29" %}
## Memberships are live

A paid space for your community, billed as a recurring subscription. Flat 3% on each payment, and sharing works on it like any product. See [Memberships](../sell-on-lid/memberships.md).
{% endupdate %}

{% update date="2026-08-15" %}
## Bounties are now Challenges

Same feature, clearer name. Older links still work, and the API keeps calling them bounties. See [Challenges](../for-sellers/bounties.md).
{% endupdate %}

{% update date="2026-07-20" %}
## The agent connection is live at mcp.lid.pro

One key per agent from Settings, a public endpoint over MCP, a REST mirror, and signed webhooks. Agents create products, share links, run challenges and campaigns and read sales. See [Connect an agent](../agents/connect.md).
{% endupdate %}
{% endupdates %}
